# Proposed Phase 11 — Operating Pack

## Scope

1. Define a minimal shared knowledge pack and platform-specific file manifests for Gemini, ChatGPT and Claude.
2. Create platform instructions enforcing validation, provenance, missing-data and no-recommendation rules.
3. Create operating workflows for single ticker, comparison and package screening.
4. Add context/token budgeting and conflict-handling checklists.
5. Validate the operating documents locally without uploading files or calling external models.

## Exit criteria

Each platform has an independent setup guide, instruction file, upload manifest and operator checklist. All artifacts preserve UTF-8, provenance and safety guardrails.

## Approval required

Phase 11 requires explicit approval. External model calls/uploads remain out of scope unless separately authorized.

## Provenance / Source Basis

The proposal follows the approved v1.0 closing plan and Phase 10 PASS result.

## Known Limitations

Platform file/token limits and retrieval behavior may change and are not fully confirmed without current external verification.

## How AI Should Use This

Use only as the Phase 11 proposal. Do not create the operating pack until approval.
