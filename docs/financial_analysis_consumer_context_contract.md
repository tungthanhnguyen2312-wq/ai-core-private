# Financial Analysis V2 Consumer context contract

Status: `AI_CONSUMER_TTM_GROWTH_AND_VALUATION_SEMANTIC_SYNC_V1` — COMPLETE.

`builders/financial_analysis_consumer_context.py` accepts only the Producer's qualitative `financial_analysis_compact/v1` record and projects it into `financial_analysis_consumer_context/v1`. It can extract a named ticker from the ordinary `analysis_bundle.json` (`tickers[ticker].financial_analysis`), the primary session bundle (`ticker_research_contexts[ticker].financial_analysis`), a direct compact record, or existing NDJSON-style ticker records. It never imports Producer Python.

The projection preserves `AVAILABLE` and `ABSENT`, issuer/analysis family, financial period, readiness, each qualitative financial state (including `profitability_state`, `margin_state`, `growth_basis`, `cash_conversion_state`, and `earnings_turnaround_state`), feature fitness (including additive TTM/QoQ fitness such as `revenue_ttm`, `profit_before_tax_ttm`, `net_income_ttm`, `operating_cash_flow_ttm`, `ttm_net_margin`, `ttm_pbt_margin`, `cfo_to_net_income_ttm`, and QoQ counterparts), deterministic supporting/counter evidence, conflicts, missing dimensions, warnings, valuation hints, Producer source/content/lineage identities, and `is_actionable=false`. It accepts the Producer's compact state-field spelling (for example `profitability_state`, `cash_conversion_state`, `earnings_turnaround_state`) as well as a state/basis object if the contract evolves without changing meaning. Unknown additive compact fields are ignored rather than crashing the adapter. Where a security-decision card wraps the compact object as `financial_analysis.compact`, it additionally preserves only that card's already-authored `current_financial_weakness`, `future_financial_invalidation_watch`, and `FA_V2_TURNAROUND_CONTEXT` namespace; it does not invent or promote them into a stance, valuation, or execution signal. Consumer never calculates TTM, P/E, P/S, growth, margin, or CFO/NI, and never retunes Producer research stance from these fields.

The adapter rejects an unsupported contract version, ticker mismatch, actionability drift, and any raw financial value fields. It never calculates or exposes ratios, values, scores, ranks, forecasts, target prices, valuation conclusions, recommendations, or sizing. `RESEARCH_PROXY` (including `CROSS_PROVIDER_UNRESOLVED_SCALE`) remains directional-only research context; it cannot be described as authoritative. `NOT_APPLICABLE` is an applicability boundary, while `BLOCKED`, `UNAVAILABLE`, and `ABSENT` are visible authority/coverage limitations — none means zero, neutral, or weak financial evidence.

`next_session_decision_context.py` also preserves the optional root `financial_analysis` session metadata as `financial_analysis_session_summary`. It is explicitly `UNAVAILABLE` for historical bundles that did not supply V2 and it does not alter any of the nine Producer transition sections.
